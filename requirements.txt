# Exact versions required to reproduce the results in this repository.
#
# v1.0.0 listed these as lower bounds (`>=`). That does not pin the numerical
# output: `src/paper_experiments.py` fixes the random seeds, but the fit of
# scikit-learn's HistGradientBoostingRegressor is not guaranteed to be
# bit-identical across versions, so a `>=` install can silently produce
# different ATE estimates from the ones reported in the manuscript.
#
# From v1.0.1 the versions below are exact. The set is exactly what the source
# imports — pandas, numpy, scikit-learn, statsmodels, lightgbm, xgboost,
# matplotlib and scipy — and nothing else. In particular the repository does
# not depend on EconML (or on `linearmodels`), despite the acronym in the
# title: the DML implementation is self-contained in `src/dml.py`.
#
# Install with:  pip install -r requirements.txt
